# TechnoGuru — Telegram Mini App Plugin

Этот плагин помогает собрать Telegram Mini App с нуля — от идеи до работающей ссылки.

## Доступные скиллы

- **miniapp-welcome** — полный мастер: бриф → дизайн → логика → код → деплой
- **miniapp-events** — добавить афишу событий в существующий мини-апп
- **deploy-vps** — задеплоить готовый проект на VPS

## Как использовать

Напиши в чате что хочешь сделать — Клод подберёт нужный скилл и запустит его.

Примеры триггеров:
- «Хочу собрать Telegram Mini App для своего клуба»
- «Добавь афишу событий в мини-апп»
- «Задеплой проект на сервер»

## Технический фундамент

Все скиллы используют единую техническую базу из `core/telegram-miniapp-fundamentals.md`.
Стек фиксирован: Node.js + Telegraf v4 + Express + Vanilla JS + PM2 + nginx.
Клод принимает все технические решения сам — пользователя о стеке не спрашивает.
