# CHANGELOG

## v1.2.0 — 2026-05-12

### Улучшения

**Три независимых трека сбора данных (miniapp-welcome, deploy-vps):**
- Сервер и домен — отдельные треки, выясняются независимо друг от друга
- Если сервера нет → инструкция как купить с нуля
- Если домена нет → варианты покупки или бесплатный поддомен
- Каждый трек ждёт своего ответа перед следующим вопросом

**Поддержка российских серверов — прокси (новый Трек Б):**
- После получения IP сервера — сразу вопрос «сервер в России?»
- Если да: объяснение почему нужен прокси (Telegram блокирует российские IP)
- Где купить: proxy6.net, proxys.io, proxyline.net
- Что выбирать: HTTPS, не SOCKS5, страны Европы
- Формат передачи: `http://user:password@IP:PORT`
- Прокси пробрасывается в `.env` как `TELEGRAM_PROXY_URL`
- Без прокси деплой на РФ-сервер не продолжается

**Чекпоинты прогресса (miniapp-welcome, deploy-vps):**

**Настройка DNS и поддоменов (deploy-vps, новый этап 1.5):**
- Пошаговая инструкция создания A-записи для любого регистратора
- Разница между основным доменом (@) и поддоменом
- Timeweb — конкретный путь в панели
- Команды проверки (`ping`, dnschecker.org)
- Предупреждение: certbot выдаст ошибку пока DNS не разошёлся

## v1.0.0 — 2026-05-12

### Первый релиз

**Core:**
- `telegram-miniapp-fundamentals.md` — технический фундамент: стек, архитектура, паттерны кода

**Skills:**
- `miniapp-welcome` — мастер сборки Welcome Mini App с нуля (7 этапов: бриф → дизайн → логика → код → деплой)
- `miniapp-events` — добавление афиши событий: карточки, ближайшее событие, умные метки дат
- `deploy-vps` — деплой на VPS: Ubuntu, Node.js, PM2, nginx, SSL

**Templates:**
- `welcome-miniapp/` — готовый стартовый шаблон (bot + miniapp + json-файлы)

**Ключевые технические решения зафиксированы:**
- `chat_member` обязателен в `allowedUpdates` (иначе приветствие не работает при вступлении по ссылке)
- `bot.launch()` не должен быть await (бесконечный polling)
- В группах — только URL-кнопка (не `web_app`)
- initData валидируется через HMAC-SHA256 на backend
